# Read+Listen local

Run Whisper locally to align an EPUB with its M4B audiobook and generate a JSON sync file. Then read along as the audiobook plays. The project includes two standalone apps: a sync engine and a player.

| Component | Purpose |
| --- | --- |
| [Read & Listen Sync Engine 3](engine/) | Transcribes the audiobook locally with faster-whisper and exports a versioned `*.sync-v2.json` sidecar. |
| [Read & Listen Player](player/) | Loads an EPUB, M4B and the sidecar in a local browser player as a test. It follows the narrator, highlights the current word and sentence, and lets you seek by selecting text. |

## Try the player

Install Python 3.11 or 3.12. From the repository root:

```powershell
py -3.12 -m venv player\.venv
player\.venv\Scripts\python.exe -m pip install -r player\requirements.txt
player\Iniciar_Reproductor.bat
```

Load the [22-second excerpt from Alice's Adventures in Wonderland](examples/) to try synchronization with real narration. The player uses temporary disk space for the files you load and listens on your own computer.

## Generate a sidecar

Install Python 3.11 or 3.12 and put FFmpeg and ffprobe on PATH. On Windows, run `engine\instalar.bat`, then `engine\iniciar.bat`. Select the EPUB and its audio, pick CPU or an available NVIDIA GPU, and click **Synchronize**. Engine 3 runs Whisper locally, detects the narration language automatically, and lets you switch the interface between English and Spanish. See the [engine guide](engine/README.md) for details.

## Integrate with another player

See the [interoperability specification](docs/sync-format.md) and the [example sidecar](examples/example.sync-v2.json). A player can implement this format directly. It can also add adapters for other timing formats. Producers can generate compatible files as long as they use the same timing units, section identifiers and word coordinates.

The current format has no dependency on a particular account, network service or speech recognition model. It is tied to the exact EPUB and audio editions that were aligned. The source code is licensed under [GPL-3.0-only](LICENSE).

## Resumen en español

El motor crea un JSON con los tiempos del EPUB y el M4B. El reproductor carga los tres archivos y resalta el texto al ritmo del audio. Para integrar otro lector, empieza por la [especificación del formato](docs/sync-format.md) y el [ejemplo de Alicia](examples/).
