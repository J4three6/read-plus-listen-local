Read & Listen Player

Consulta el README principal para crear el entorno local con Python y las
dependencias de requirements.txt. Ejecuta Iniciar_Reproductor.bat y selecciona
o arrastra el EPUB, el M4B y su archivo JSON a las zonas correspondientes.

El navegador copia los archivos a un directorio temporal del servidor local.
Un M4B grande puede tardar en cargarse y requiere espacio libre equivalente.
El reproductor escucha en 127.0.0.1.
